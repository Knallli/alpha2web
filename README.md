# alpha2web

Web UI for managing Sony Alpha cameras remotely, built on [alpha2go](https://github.com/Knallli/alpha2go).
Exporters (e.g. Immich) are compile-time plugins, see `plugin/`.

Status: skeleton. Nothing is wired to the camera yet.

## AI disclosure

Large parts of this repository were written with the help of an AI coding assistant (Claude) and reviewed by the author.
